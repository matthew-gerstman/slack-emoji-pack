Slack Emoji Pack - Slack-Optimized Set
=====================================

This repository now includes a Slack-optimized version of all 117 emoji GIFs.

Location in repo:
- gifs_slack_optimized/  (all 117 optimized GIFs)

Each GIF is:
- Max 128x128px
- Typically < 500KB (largest ~440KB)

To use:
1. Download the repo as ZIP from GitHub:
   https://github.com/matthew-gerstman/slack-emoji-pack/archive/refs/heads/main.zip
2. Extract and upload GIFs from gifs_slack_optimized/ into Slack.
